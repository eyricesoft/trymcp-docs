You need a [TryMCP account](https://app.trymcp.io/register).

## 1. Create a server

Open the [dashboard](https://app.trymcp.io). Go to **Servers** and click **Create Server**.

- Set **Title** to `GitHub Tools`.
- Pick a **Category**.
- Choose an available **Subdomain**.
- Use **Public** for this example. It only reads public data.
- Click **Create**.

## 2. Add a tool

Open the server. Click **Create New Tool**.

Name it `fetch_repo_stats`.

Add a required string parameter named `repo`. Its value will be an `owner/repo` pair.

Paste this tool body into the editor:

```javascript
const response = await sdk.http({
  url: `https://api.github.com/repos/${params.repo}`,
  headers: { "User-Agent": "TryMCP-Tool" },
});

if (!response.ok) {
  throw new Error(`GitHub returned ${response.status}`);
}

const repo = response.json();

return {
  stars: repo.stargazers_count,
  forks: repo.forks_count,
  language: repo.language,
};
```

Keep **Active** on. Click **Create**.

## 3. Run it

Click **Run**. Enter `octocat/Hello-World` for `repo`. Run the tool and check **Output**.

You should see stars, forks, and language. If it fails, check the message in Output.

## 4. Connect a client

Open your server's **Integration** tab. Pick your client and copy its config.

- [Claude Desktop](/connect/claude-desktop)
- [Cursor or VS Code](/connect/cursor-and-vscode)
- [Windsurf or Cline](/connect/windsurf-and-cline)

For private tools, choose an access mode in [Security](/security). Store API credentials in [Secrets](/secrets).
