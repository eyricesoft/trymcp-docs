TryMCP hosts [MCP](https://modelcontextprotocol.io) servers. Write a JavaScript tool in your browser. Save it. Your AI client can call it through a URL.

## Two things to know

- A **server** has an endpoint, tools, secrets, and access settings.
- A **tool** takes inputs, runs your code, and returns a result.

Your code can call an HTTPS API, query a database, or work with data.

```text
AI client -> TryMCP tool -> Your API or database
```
