---
title: "Windsurf and Cline"
description: "Connect through the config generated by TryMCP."
---

Both configs use `mcp-remote`. You need Node.js with `npx` on your computer.

## Windsurf

Open Windsurf's MCP settings and edit `mcp_config.json`. Add this entry under `mcpServers`:

```json
{
  "mcpServers": {
    "trymcp": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote@latest",
        "https://your-server.trymcp.io/mcp"
      ]
    }
  }
}
```

## Cline

Open **MCP Servers** in Cline. Choose **Configure MCP Servers**. Add this entry and keep your existing servers:

```json
{
  "mcpServers": {
    "trymcp": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote@latest",
        "https://your-server.trymcp.io/mcp"
      ]
    }
  }
}
```

## Private servers

Replace the URL with your server's endpoint. For **Unlisted**, use the full URL with its secret path.

For **API Key**, append these two items to `args`:

```json
["--header", "Authorization: Bearer YOUR_API_KEY"]
```

Replace `YOUR_API_KEY` with your key. For **OAuth**, complete the provider's sign-in flow when prompted.

Reload the client's MCP server list. Check that the server is connected and your tools are active.
