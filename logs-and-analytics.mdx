description: "Check calls, errors, and usage."
---

## Traffic logs

Open **Requests** under **Traffic** in the dashboard. Pick a call to inspect its request and response details.

Use the filters to narrow the list. Start with the server and date range.

## Error logs

Open **Errors** under **Traffic** to check errors. Select an entry to see its details.

If a tool fails, check its inputs, secrets, and upstream response. Run it in the editor to see console messages in **Output**.

## Analytics

Open **Analytics** for usage charts. The server page also has an analytics tab.

Choose a date range to compare request counts, errors, and latency. Available data depends on your calls and plan limits.
